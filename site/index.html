Create projects and start, pause, switch, or stop without opening a full dashboard.

Preview installation

Up and tracking in three steps.

This early build is not notarized because Spann does not yet have an Apple Developer certificate. macOS will show an unidentified developer warning.

Download and install

Open the downloaded DMG and drag Spann.app into the Applications shortcut.

Open with confirmation

Control-click Spann.app, choose Open, then confirm Open. If needed, use Privacy & Security → Open Anyway.

Allow idle detection

Choose Allow in Spann and approve Input Monitoring. Spann reads inactivity duration, never keys or clicks.
